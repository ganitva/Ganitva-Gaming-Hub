# GANITVA Stable Landing v1

This package fixes the landing/student portal layout for 100% browser zoom and common desktop/mobile screen sizes.

## Files
- `index.html` — main landing page
- `student.html` — stable student portal page
- `chapter1_multigame.html` — Chapter 1 multi-game engine
- `admin.html` — existing admin prototype

## GitHub Pages
Replace/upload these files in the repository root. The Chapter 1 button now opens `chapter1_multigame.html`.

The layout uses responsive CSS, no fixed-width page containers, no horizontal overflow, and compact spacing so the first screen remains clean at 100% browser zoom. Smaller screens stack the cards automatically.
