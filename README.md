# GANITVA Deployment v3

This is a GitHub-Pages-ready static prototype.

## Files
- index.html — main landing page
- student.html — student portal
- chapter1.html — Chapter 1 games
- admin.html — prototype admin/teacher portal

## Test
Open index.html in a browser and navigate through the portal.

## Publish
Upload all four HTML files to a GitHub repository. Enable GitHub Pages from the repository's Pages settings. Students then use the published URL.

## Important
This version is a static prototype. localStorage is browser-specific, so it is NOT a shared school database. The admin PIN is also not secure because it is client-side.

For the production version, add a backend/database (for example Supabase/Firebase or another server-side system) for authentication, shared question banks, student progress and teacher analytics.
